# Benchmark v2 reports

Measured JSON reports belong here after validation. A valid report must include:

- source commit and creation timestamp;
- dataset and model checksums;
- split manifest and label-quality tier;
- calibrated validation threshold;
- per-glacier hard, boundary, and area metrics;
- glacier-level bootstrap confidence intervals;
- explicit allowed and prohibited claims.

No placeholder numerical reports are committed because templates must not be
mistaken for evidence.
